# Shell Script DevOps Project

A beginner-friendly DevOps automation project built using Bash scripting, Node.js, PM2, and GitHub.

## Features

- Automated deployment script
- PM2 process management
- Log monitoring and analysis
- Log cleanup automation
- GitHub integration
- Linux shell scripting

## Tech Stack

- Ubuntu WSL
- Bash
- Node.js
- PM2
- Git
- GitHub

## Project Structure

shell_script_prj/
│
├── app/
├── scripts/
├── logs/

## Scripts

### deploy.sh
Automates deployment process.

### analyze_logs.sh
Analyzes PM2 application logs.

### cleanup_logs.sh
Deletes old log files automatically.

node server.js
